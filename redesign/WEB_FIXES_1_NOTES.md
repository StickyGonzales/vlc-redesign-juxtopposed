| 1 | **Ctrl+P opens Settings.** VLC's core binds nothing to Ctrl+P on Windows or Linux (only macOS, for previous title; Windows and Linux use Shift+O), so no VLC action moves and the vlc profile's keys stay as they are. The real cause was on Linux: from Qt 6.9, application-wide QML shortcuts are ignored in the X11 compositor's offscreen window, so Ctrl+P, and also Ctrl+E, Ctrl+I, Ctrl+L, F11 and the other `GlobalShortcuts.qml` keys, did nothing. A wrapper of Qt Quick's shortcut context check accepts them when the window showing the interface is visible, as Qt 6.8 did. Only built with Qt 6.9 or newer: the Windows build (Qt 6.8.3) compiles exactly as before.
